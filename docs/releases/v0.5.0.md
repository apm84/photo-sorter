## Photo Sorter 0.5.0: Windows installer, in-app setup and updates

**Download:** `PhotoSorterSetup.exe` below. No Python or command line needed. It installs for your Windows user only, with no admin prompt.

### New
- **Windows installer.** Photo Sorter now installs like a normal app, with a Start menu entry and an optional desktop shortcut. HEIC (iPhone) photos are supported in the installed app.
- **Setup inside the app.** The first time it opens, Photo Sorter:
  - checks your graphics card (DirectML) and suggests GPU or CPU mode,
  - checks free disk space,
  - asks for your photo folders and the output folder,
  - downloads the AI models (about 950 MB, from the `models-v1` release). The download shows progress, resumes if it's interrupted, retries on errors, and checks every file's SHA-256,
  - runs a quick self-test.
  If you already have the models from an earlier source install, it offers to copy them instead of downloading them again.
- **Updates inside the app.** Use *Help > Check for updates* (it can also check once a day). It shows the release notes, downloads the new installer, checks its SHA-256 against this release, then closes the app, upgrades it and opens it again.

### Kept as they are
Your photos, the output folder with its `_index`, your settings, family sync pairing and models all live outside the install folder. Installing, updating or uninstalling never touches them. Your original photo folders are only ever read.

### Upgrading from the source (zip) install
Install `PhotoSorterSetup.exe` and open Photo Sorter. Setup picks up your earlier folders from `%LOCALAPPDATA%\PhotoSorter\gui.json`, so the same output folder, index, people, albums and Clean up decisions carry on. It also finds the models in your old `...\PhotoSorter\...\models` folder and copies them after checking them. If family sync was set to start at sign-in, the installed app switches that over to itself the first time it opens.

### Notes
- The installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Choose *More info > Run anyway*.
- The AI models are not inside the installer. They download once during setup.
