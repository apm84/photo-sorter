## Photo Sorter 0.6.1: search page starts reliably

- The search page (and Clean up, Verify, Family sync) now starts when Photo Sorter opens, once this
  output folder already has an index, and stays running during a scan. After the first sort run
  creates the index, the page is started automatically too.
- Opening the page waits until it is actually listening (up to about 30 seconds, with a
  "Starting search page..." line in the log) instead of always waiting 1.2 seconds and hoping.
  That 1.2 second wait was why some clicks during a scan showed `http://127.0.0.1:8765/ refused
  to connect`.
- If starting fails, the full error is written to `%LOCALAPPDATA%\PhotoSorter\photosorter.log`
  and shown in a message, and the next click tries again (0.6.0 could get stuck after a silent
  failure and never retry).
- If port 8765 is already in use, the next free port is used and the browser is pointed there.
